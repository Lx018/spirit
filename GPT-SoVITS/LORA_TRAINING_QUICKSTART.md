# Quick Start: LoRA Style Training

## Overview

This simplified training script works directly with WebUI-generated data.

## Data Format

### Input Files

1. **Audio Files** (already generated by WebUI):
   - Location: `/home/itx/Desktop/spirit/GPT-SoVITS/out/*.wav` (or wherever your WAV files are)

2. **Transcription List** (already generated by WebUI):
   - File: `output/asr_opt/out.list`
   - Format: `wav_path|speaker|language|text`
   - Example:
     ```
     /home/itx/Desktop/spirit/STTS/out/1.wav_0000000000_0000084800.wav|out|EN|The sun rises gently over the quiet hills.
     ```

3. **Style Labels** (YOU CREATE THIS MANUALLY):
   - File: `output/asr_opt/style_labels.txt`
   - Format: `wav_path|style_id`
   - Example:
     ```
     /home/itx/Desktop/spirit/STTS/out/1.wav_0000000000_0000084800.wav|0
     /home/itx/Desktop/spirit/STTS/out/10.wav_0000000000_0000089280.wav|1
     /home/itx/Desktop/spirit/STTS/out/100.wav_0000000000_0000089280.wav|2
     ```

## Style IDs (Define Your Own)

You can use any mapping you want. Example:
- `0` = neutral
- `1` = happy/excited  
- `2` = sad/melancholic
- `3` = angry/intense
- `4` = surprised/questioning

Or use prosody-based labels:
- `0` = slow and soft
- `1` = fast and energetic
- `2` = varied and expressive

### 1. Create Style Labels

Create `output/asr_opt/style_labels.txt`:

```bash

cd /home/itx/Desktop/spirit/GPT-SoVITS

nano output/asr_opt/style_labels.txt
```

Paste something like:
```

/home/itx/Desktop/spirit/STTS/out/10.wav_0000000000_0000089280.wav|0
/home/itx/Desktop/spirit/STTS/out/100.wav_0000000000_0000089280.wav|1
/home/itx/Desktop/spirit/STTS/out/101.wav_0000000000_0000121920.wav|1
...
```

**Pro tip**: Listen to each file and label based on the emotion/style you hear, or use prosody analysis tools to auto-generate labels.

### 2. Check the Config

Edit `GPT_SoVITS/configs/style_lora.json` if needed:

```bash
nano GPT_SoVITS/configs/style_lora.json
```

Make sure:
- `base_model_path` points to your trained SoVITS model
- `num_styles` matches your max style_id + 1 (e.g., if you use 0-4, set to 5)

### 3. Run Training

```bash
cd /home/itx/Desktop/spirit/GPT-SoVITS

python GPT_SoVITS/s2_train_lora_simple.py --config GPT_SoVITS/configs/style_lora.json
```

### 4. Monitor Training

The script will:
- Load your audio and labels
- Extract features automatically
- Train only the LoRA adapter (~1-2% of model size)
- Save checkpoints every 500 steps to `checkpoints_lora/`

### 5. Use the Trained LoRA

After training, you'll have checkpoints like:
```
checkpoints_lora/lora_step_500.pt
checkpoints_lora/lora_step_1000.pt
...
```

Use these with inference (we'll create an inference script next).

Or split randomly into multiple styles:

```python
# Python script to randomly assign styles

with open('output/asr_opt/out.list', 'r') as f:
    lines = f.readlines()

with open('output/asr_opt/style_labels.txt', 'w') as f:

        wav_path = line.split('|')[0]
        style_id = random.randint(0, 4)  # Random style 0-4

```

## Advanced: Auto-Label Based on Prosody

Extract features and cluster:

```python
import librosa
import numpy as np
from sklearn.cluster import KMeans

def extract_prosody(wav_path):
    y, sr = librosa.load(wav_path, sr=16000)
    
    # F0 (pitch)
    f0 = librosa.yin(y, fmin=80, fmax=400)
    mean_f0 = np.nanmean(f0)
    
    # Energy
    rms = librosa.feature.rms(y=y)[0]
    mean_energy = np.mean(rms)
    
    # Speaking rate
    zcr = librosa.feature.zero_crossing_rate(y)[0]
    mean_zcr = np.mean(zcr)
    
    return [mean_f0, mean_energy, mean_zcr]

# Extract features for all files
features = []
wav_paths = []

with open('output/asr_opt/out.list', 'r') as f:
    for line in f:
        wav_path = line.split('|')[0]
        try:
            feat = extract_prosody(wav_path)
            features.append(feat)
            wav_paths.append(wav_path)
        except:
            pass

# Cluster into N styles
features = np.array(features)
kmeans = KMeans(n_clusters=5)
labels = kmeans.fit_predict(features)

# Save labels
with open('output/asr_opt/style_labels.txt', 'w') as f:
    for wav_path, label in zip(wav_paths, labels):
        f.write(f"{wav_path}|{label}\n")
```

## Troubleshooting

**"No style labels found"**
- The training will still work, all samples use style 0
- Create `output/asr_opt/style_labels.txt` for multi-style training

**"Error loading {wav_path}"**
- Check that WAV files exist
- Check file permissions
- Verify paths in `out.list` are correct

**CUDA out of memory**
- Reduce `batch_size` in config (try 4 or 2)
- Use smaller `segment_size`

**Training too slow**
- Make sure `fp16_run: true` in config
- Use fewer `num_workers` if CPU is bottleneck
- Check GPU utilization with `nvidia-smi`
